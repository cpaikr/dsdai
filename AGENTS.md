# Repository instructions

## Scope

- This repository owns the `dart-dsd` agent skill: guidance and a bundled,
  dependency-free helper for reading and editing Korean DART Editor `.dsd`
  documents.
- `skills/` is the published skill catalog, laid out like `../agent-scripts`:
  `skills/<name>/SKILL.md`, `agents/openai.yaml`, and directly linked
  resources. Repo-local `.agents/skills/` and `.claude/skills/` are generated by
  `sjskills` from `sjskills.toml`; never edit those copies.
- Observed format facts live in `skills/dart-dsd/references/format.md`, written
  in our own words and free of any sample's content.

## Confidentiality

- This repository is public. `fixtures/private/` holds real audit `.dsd` files
  and locally installed DART schemas; it is git-ignored and its contents, file
  names, sizes, and derived values must never be committed, quoted in docs,
  tests, or commit messages, or uploaded.
- Public tests and examples use only independently authored synthetic
  fixtures (`fixtures/public/`, generated by
  `skills/dart-dsd/evals/make_fixture.py`).
- Do not copy DART XSD/DTD text or DART Editor form wording (insertion
  comments, library names) into the repository; describe behavior in our own
  words and use invented strings in fixtures.

## Skill layout

- Keep `SKILL.md` frontmatter to `name` and `description`, matching the
  directory name. Link every agent-read Markdown resource directly from
  `SKILL.md` and name every script by its relative path.
- Bundled files stay inside the skill directory: no symlinks or parent links.
- The helper `skills/dart-dsd/scripts/dsd.py` must stay standard-library only
  and support Python 3.9+.

## Validation

- `python scripts/check.py` runs package checks and unit tests, and — when
  `fixtures/private/` exists — a no-content round-trip over the private corpus.
- Run it after changing the skill, the helper, or fixtures.
